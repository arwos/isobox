# Работа с roadmap isobox

- Перед выбором задачи читай `ROADMAP/ARCHITECTURE.md`, соответствующие `TASK.md`, `CONTEXT.md`, `QA.md` и зависимости задачи.
- Выполняй ровно одну выбранную пользователем задачу за запрос. Начинай только задачи с закрытыми зависимостями.
- Сохраняй согласованные требования безопасности. Не ослабляй профиль молча и не запускай приложение, если обязательное ограничение не удалось применить.
- Обновляй статус задачи, контекст технических решений и фактически выполненные QA-команды. Не отмечай проверки успешными, если они не запускались.
- Команды сборки, форматирования и QA пока не установлены: репозиторий содержит только `go.mod`. Добавляй проверенные команды в документацию вместе с первой реализацией.
- Не включай несвязанные пользовательские изменения в commit. Для реализации используй формат commit `<TASK-ID>: <краткое название>`.
