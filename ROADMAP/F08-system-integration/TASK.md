# F08 — Необязательная системная интеграция

## Зависимости

- Требует: F02, F04.
- Интеграция не является обязательной для `isobox run`.

## Задачи

- [ ] F08-T01 — Добавить пользовательские desktop launchers и системные defaults.
  - Шаги: формировать/обновлять launcher для пользователя; читать системные значения по умолчанию; дать пользователю возможность переопределять defaults; не внедрять принудительную admin policy.
  - Приёмка: launcher запускает isobox с выбранным профилем и app-id; при отключённой интеграции базовый CLI работает; пользовательский override имеет приоритет над системным default.
