# F08 — Необязательная системная интеграция

## Зависимости

- Требует: F02, F04.
- Интеграция не является обязательной для `isobox run`.

## Задачи

- [x] F08-T01 — Добавить пользовательские desktop launchers и системные defaults.
  - Шаги: формировать/обновлять launcher для пользователя; читать системные значения по умолчанию; дать пользователю возможность переопределять defaults; не внедрять принудительную admin policy.
  - Приёмка: launcher запускает isobox с выбранным профилем и app-id; при отключённой интеграции базовый CLI работает; пользовательский override имеет приоритет над системным default.
  - Реализация: `isobox integration install/remove` управляет пользовательскими `.desktop` файлами; настройки накладываются по приоритету built-in → первый системный XDG config → пользовательский XDG config → явные поля профиля.
  - Результат: live-приёмка в пользовательской X11-сессии подтвердила запуск установленного `.desktop` через `gio launch`, передачу spaced profile path и argv с зарезервированными символами, работу базового CLI без launcher/settings, приоритет XDG system/user overrides и безопасное удаление launcher без изменения профиля или HOME. Повторяемая проверка: `source/README.md`.
