# F03 — Проверка возможностей хоста

## Зависимости

- Требует: F01, F02.
- Используется F04–F07.

## Задачи

- [x] F03-T01 — Проверять rootless-предпосылки до запуска.
  - Шаги: проверить Linux, `bwrap`, включённые user namespaces, наличие `pasta`/`slirp4netns`; при `proxy` проверить TUN-устройство и возможность создать/подключить TUN в нужном namespace; проверять применимость запрошенных лимитов.
  - Приёмка: диагностика перечисляет отсутствующую возможность и конкретное действие; запуск прекращается до старта приложения, если любая обязательная возможность недоступна.
- [x] F03-T02 — Выбирать backend сети с проверкой его возможностей.
  - Шаги: предпочитать `pasta`; переходить к `slirp4netns`, когда pasta отсутствует или не может выполнить конкретный профиль; сопоставить port forwarding, IPv4/IPv6, DNS и гарантии режима до выбора.
  - Приёмка: preflight читает объявленные возможности установленных helper; выбирает `pasta` первым, допускает `slirp4netns` лишь при сохранении семантики; при неподдерживаемом правиле или недоказанной сетевой гарантии завершает запуск ошибкой до приложения.
