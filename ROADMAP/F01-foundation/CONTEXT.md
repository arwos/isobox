# F01 Контекст

- Репозиторий на старте содержит только `go.mod`: `module github.com/arwos/isobox`, `go 1.26.8`.
- Целевая платформа — Linux; интерфейс — модульный CLI для GUI-приложений и терминальных команд.
- Согласованный запуск: `isobox run [--profile=/path/to/profile.unic] [--app-id=ID] -- app [args...]`; без профиля используется пользовательский `default.unic` согласно F02-T03.
- `isobox ps` показывает активный зарегистрированный PID приложения, app-id, cwd запуска CLI, RSS/CPU этого PID и сетевой режим профиля. CPU снимается коротким интервалом; колонка INTERNET описывает политику `off`/`direct`/`proxy`, не проверяет внешнее соединение.
- Команда приложения задаётся при запуске, а не в профиле.
- `--app-id`, если передан на CLI, принимает ASCII-идентификатор до 64 символов: первая позиция — буква/цифра, далее допускаются буквы, цифры, точка, `_`, `-`. Slash и `..` в начале невозможны; каталог позднее должен быть изолирован от прямого пути пользователя.
- CLI пока только разбирает запрос и отказывается запускать приложение без sandbox runtime; это исключает случайный запуск напрямую на хосте.
- Проверены Go 1.26.8, gofmt и сборка; подробности ограничений окружения записаны в `QA.md`.
