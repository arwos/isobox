# F04 — Bubblewrap sandbox

## Зависимости

- Требует: F01, F02, F03.
- Используется F05–F07 и F08.

## Задачи

- [~] F04-T01 — Собирать минимальный root и запускать команду через bwrap.
  - Шаги: автоматически предоставить базовые системные пути только для чтения; создать proc/dev/tmp и рабочий каталог согласно проверенной схеме; отделить аргументы приложения от аргументов isobox.
  - Приёмка: host root/home не становятся доступны целиком; каждый обязательный mount применён либо запуск отменён; аргументы после `--` передаются приложению без изменений; завершение и сигналы передаются с предсказуемым кодом.
  - Реализация завершена; runtime runner `tests/f04-sandbox/base-runtime/run.sh` проверяет изоляцию root/runtime путей, очищенное окружение, read-only system paths, точную передачу argv/exit status, SIGTERM и fail-closed при симулированной ошибке обязательного `/usr` bind. Статические проверки пройдены; пользовательский runtime-результат ещё нужен.
- [~] F04-T02 — Подключать явные mounts и изолированный HOME.
  - Шаги: обработать только профильные host paths; смонтировать профильный HOME в фиксированный sandbox HOME; иначе создать приватный каталог под `/tmp`, переиспользовать его по `--app-id` и сохранить после выхода.
  - Приёмка: разные пары профиль/app-id получают разные каталоги; заданный путь профиля используется точно; права каталога исключают доступ других пользователей; неподдержанный mount блокирует запуск.
  - Реализация завершена; runtime runner `tests/f04-sandbox/run.sh` проверяет явные read-only/writable mounts, persistence explicit/managed HOME, изоляцию пар profile/app-id, права `0700` и fail-closed на недоступном mount. Статические проверки пройдены; пользовательский runtime-результат ещё нужен.
- [~] F04-T03 — Реализовать ручные GUI-разрешения профиля.
  - Шаги: отдельные grants для Wayland/X11, audio, GPU и desktop integration; не предоставлять полный D-Bus по умолчанию и не подключать порталы.
  - Приёмка: каждое разрешение можно включить независимо; выключенные socket/device/bus недоступны приложению.
  - Реализация завершена; runtime runner `tests/f04-sandbox/gui-grants/run.sh` создаёт временные Unix sockets и проверяет grants по одному, отсутствие ресурсов по умолчанию и fail-closed для недоступных/небезопасных разрешений. GPU-путь проверяется по доступным устройствам хоста; без них запуск с grant обязан отказать до payload. Статические проверки пройдены; пользовательский runtime-результат ещё нужен.
